CLI Box 是一款专注于从 GitHub Releases 安装和维护命令行工具的 Windows 桌面应用。

内置 GitHub CLI、jq、yq、fzf 和 asc 等常用开发者工具。CLI Box 会检测已安装版本、查询最新稳定版本，并清楚显示是否有可用更新。

每次安装都会执行透明且可验证的流程：解析官方 Release、选择 Windows x64 资源、下载发布者提供的校验文件、验证 SHA-256、按需解压，并安装到用户选择的目录。

你可以浏览近期稳定版本并降级、卸载已管理的二进制文件，或从兼容的 GitHub 仓库添加自定义工具。高级设置支持自定义资源命名、校验文件、平台映射、版本命令和安装目录。

界面支持简体中文、英文以及跟随系统语言。可选的“说明”功能可使用用户自己的 DeepSeek API 密钥总结公开仓库信息；安装和版本管理不依赖 DeepSeek。

CLI Box 不包含广告、分析或遥测，也不要求注册账号。GitHub Token 为可选项，仅用于提高 GitHub API 速率限制。

注意：工具必须提供兼容的 Windows 可执行文件或受支持的压缩包，并提供 SHA-256 校验文件。校验和用于验证下载完整性，但不能代替对上游发布者的信任。
