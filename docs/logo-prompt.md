# CLI Manager logo prompt

## Primary prompt

Create a premium, minimal app icon and open-source project logo for “CLI Manager”, a cross-platform desktop application that securely installs, verifies, updates, and organizes command-line tools. Build a distinctive geometric symbol by combining an abstract terminal prompt chevron with a modular package/container shape and a subtle circular refresh motion. Communicate precision, trust, speed, and developer craftsmanship without using any existing company logo or trademark. Use a deep graphite-to-midnight navy base with restrained electric cyan and emerald accents, crisp vector geometry, balanced negative space, soft dimensional layering, and excellent legibility at 16×16, 32×32, and 512×512 pixels. Place the design inside a centered squircle tile that occupies about 86% of the 1:1 canvas, uses a clearly visible corner radius of about 22% of the tile width, and has fully transparent outer padding so the silhouette reads as rounded in the macOS Dock and Windows taskbar. No words, no letters, no screenshots, no photorealism, no mascots, no padlock cliché, no GitHub Octocat, no Apple or Windows marks, no border frame, no excessive glow, no thin fragile lines. Deliver a clean flat-vector master with a subtle polished depth, transparent-background variant, light-background variant, and dark-background variant.
